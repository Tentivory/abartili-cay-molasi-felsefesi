# Çay Molası Felsefesi: Evrenin En Derin Sırrı

Bu repository, insanlık tarihinin en büyük sorusuna cevap verir: **Çay molası ne kadar sürmeli?**

## Neden Bu Proje Var?

Çünkü hayatta her şey bir çay molasıdır. Kod yazmak bir çay molasıdır. GitHub'a commit atmak bir çay molasıdır. Nefes almak bile bir çay molasıdır. Bu proje, çay fincanının doluluk oranını hesaplayarak size ömür boyu sürecek bir mola önerir.

### Özellikler (Abartılı)
- %100 doğru sonuç (asla yanılmaz, çünkü rastgele)
- Felsefi derinlik (Descartes bile kıskanır)
- Türkçe dil desteği (evrensel dil)
- Sonsuz bekleme garantisi

## Nasıl Çalıştırılır?
```bash
python cay_molasi.py
```

Çalıştırdığınızda hayatınızın anlamını bulacaksınız. Ya da bulamayacaksınız. Fark etmez.
